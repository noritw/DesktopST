## 測試前準備

- **Pixel 10a 實機**，裝的是最新一次 `MobileST.bat` → `[1]` 打出來的 debug APK
  （打包前先確認 `src/mobile/README.md` 那兩個陷阱：Capacitor 外掛要在
  `dependencies`、`JAVA_HOME` 不能用 Android Studio 的 jbr）
- **電腦端 DeST 要開著**（同步的另一端就是它，關掉的話比對畫面什麼都抓不到）
- **手機與電腦在同一個 Wi-Fi**（走區網直連；中繼模式不在這份的驗證範圍）
- 建議先確認 header 左上角的兩字標籤是「區網」，以及「關於」頁的**建置時間**
  是你剛打包的那一次——**要看「更新了沒」請看建置時間，不是版本號**

> 測到異常時順手抓 log：`adb logcat | grep -i "sync\|Mixed Content"`。
> 看到 `Mixed Content` 就是 `capacitor.config.ts` 的 `androidScheme` 又變回 `'https'`
> 了（CLAUDE.md §5 第一條）。

## 一、S2 M4 比對畫面（9 條）

- [ ] 1. 獨立 → 遙控：比對畫面出現、左右各自可選、三顆快捷鍵、確認後電腦端**不長重複**

　結果：

- [ ] 2. 遙控 → 獨立：同上，手機端不長重複

　結果：

- [ ] 3. 電腦上把某筆改名 → 比對畫面應仍配成同一列（靠 id）並標「電腦上叫⋯⋯」

　結果：

- [ ] 4. 兩邊完全相同時：該分頁顯示「完全相同」，確認鍵變成「直接切換」

　結果：

- [ ] 5. 比對畫面按取消 → **不應**出現「上次那台電腦連不上了」

　結果：

- [ ] 6. 推情境後檢查電腦端 `scenes/*.json`：`activePersonaId` 要指向電腦上真的存在的 id，
  `desktopCharacters` 的座標要維持電腦原本的值

　結果：

- [ ] 7. **刪除**（2026-08-14 追加）：在電腦上刪掉一筆 → 手機比對畫面該列選「電腦」→
  按鈕與外框轉成警告色、副標變「刪除另一邊」→ 確認時跳出逐筆清單 →
  同步後手機那份真的消失。反方向（選「手機」刪掉電腦那份）同理

　結果：

- [ ] 8. 快捷鍵防呆：按「全部用電腦」不該產生任何刪除（單邊獨有的仍是補到對面）

　結果：

- [ ] 9. **設定分頁**（S2 M5）：改電腦上的配色主題／對話限制／模組開關 → 開比對畫面
  「設定」分頁該欄位顯示不同 → 選一邊 → 同步後另一邊的值真的變成一樣，
  且**沒被選中的其餘欄位不受影響**（尤其驗證「對話限制」三欄只改一欄時，
  電腦端另外兩欄不會被送過去的請求覆蓋——見 `mobile-sync-m4-compare.md` §8.3）

　結果：

## 二、S2 M5 設定同步（6 條）

- [ ] 1. 在電腦上改配色主題 → 手機比對畫面「設定」分頁該列顯示「電腦：〈新主題〉」

　結果：

- [ ] 2. 只選「對話限制」三欄裡的一欄用手機 → 同步後電腦上**其餘兩欄維持電腦原值**，
  不會被送出的請求覆蓋成手機的值

　結果：

- [ ] 3. 切換供應商（選電腦） → 手機那個供應商如果原本沒設過模型，要補目錄預設值，
  不留空模型

　結果：

- [ ] 4. 模組開關（例如天氣）從電腦帶回手機 → 手機的天氣模組真的被打開，
  不是只有 `enabled` 欄位變了但功能沒生效

　結果：

- [ ] 5. 兩邊設定完全相同時，「設定」分頁顯示「設定兩邊完全相同」

　結果：

- [ ] 6. 快捷鍵「全部用電腦」只在設定分頁生效，不影響資料分頁的選擇，反之亦然

　結果：

> **補驗一條**（§8.5b，2026-08-14 owner 真機揪出來的漏網欄位）：
> 天氣的「潤飾」子設定（`weather.polish`，天氣訊息要不要先過一次輔助模型）
> 現在也在比對範圍內了。在電腦上把它切掉 → 手機比對畫面應該看得到這一列
> （歸在模組分組、列在天氣模組開關附近），選一邊後兩邊一致。
>
> 　結果：

## 三、對話同步（8 條）

> 出處 `mobile-mode-switch-sync.md` §8.4。**第 1 條最重要**——S2 M3 當初就是栽在
> 重複增生，最後要靠一次性腳本清電腦端資料才收拾掉。

- [ ] 1. 手機上開一則新對話聊幾句 → 切到遙控 → 對話分頁該列顯示「合併」→
  同步後電腦上出現那則，**且再切一次不會長出第二份**（這條最重要）

　結果：

- [ ] 2. S1 匯入過的對話：兩邊都不動 → 比對畫面該則應顯示「完全相同」，
  **不是**「手機上獨有」

　結果：

- [ ] 3. 兩邊各自在同一則對話裡聊幾句 → 合併後兩邊都看得到對方那幾句，
  而且**順序照時間戳交錯正確**，不是一邊接在另一邊後面

　結果：

- [ ] 4. **帶圖片的對話**：手機上傳幾張圖 → 合併 → 電腦上圖片正常顯示
  （這條在驗分批：單則帶三張圖就可能自己超過一塊）

　結果：

- [ ] 5. 電腦上把某則對話改名 → 比對畫面該列應仍配成同一列，並長出「⚠ 標題兩邊
  不同」子列 → 選一邊 → 同步後兩邊標題一致

　結果：

- [ ] 6. 對話很多時（十幾則）確認畫面不會卡，且「另有 N 則兩邊相同」預設收起

　結果：

- [ ] 7. 合併正在看的那則對話 → 手機畫面應立刻出現補進來的訊息（`state-invalidated`）

　結果：

- [ ] 8. 同步途中拔掉網路 → 完成訊息要列出哪幾則沒成功，**其餘照樣完成**；
  重連後再同步一次應該收斂，不會產生重複訊息

　結果：
