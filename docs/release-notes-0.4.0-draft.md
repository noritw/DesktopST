# DesktopST v0.4.0 — 更新說明

> 狀態：**已發佈**（2026-08-07）。  
> Tag／Release：https://github.com/noritw/DesktopST/releases/tag/v0.4.0  
> 基準：`v0.3.11` → `v0.4.0`（`main`）。

---

## 一句話

這版主軸是**手機遠端／陪聊介面長大**，並補上幾組有辨識度的介面配色：舊 `mobile.html` 退場，改走單一 React 入口；新聞陪聊與設定在手機上更完整；桌面／手機可選「森林／復古／賽博」等新主題。

---

## 給使用者看的更新（建議放進 Release）

### 手機遠端（大改）

- 手機介面全面改版：聊天、設定、角色庫、情境／世界觀／發言身分、對話清單、個人新聞報、遙控等，都在同一套新畫面。
- 遠端入口統一為單一頁面（掃 QR／開連結即可），不再依賴舊版 `mobile.html`。
- 介面配色與電腦端同步；在手機改主題也會寫回電腦。

### 介面配色（12 組）

- **新增**「森林」（淺綠＋微黃）、「復古」（深色茶褐）、「賽博」（深色・黑底＋深綠深藍，偏護眼、非霓虹）。
- **改寫**「純白」「黑白灰」為無彩度（灰階）；黑白灰不再帶綠調。
- 仍保留既有粉彩主題：薄荷、奶油、蜜桃／粉橘、水藍／粉藍綠、天空、腮紅／粉紅、薰衣草。
- 桌面「設定 → 介面」、手機主題選單、情境儲存的配色標示皆已對齊。

### 手機設定與陪聊

- 可在手機設定供應商／模型／API Key（區網直連時）、記憶、模組開關、提醒。
- **天氣**：可設位置、是否帶進對話、潤飾（CWA Key 等進階仍在電腦）。
- **新聞陪聊**：頻率與相關開關可在手機調整；個人新聞報可瀏覽、釘選、「聊這個」。
- 新增「對話」設定：最大回應字數、群組最多角色回應數、單則訊息圖片上限（與電腦同一組設定）。

### 新聞陪聊品質

- 「聊這個」時，角色看到的是**補強後的新聞上下文**（摘要不足會嘗試抓原文／輔助摘要）；聊天畫面只顯示可點的標題。
- 標題／上下文可事後查看與調整（影響之後延續話題，不重寫舊回覆）。
- 修正 Google 新聞包裝連結抓不到原文的問題。
- 手機：確認聊新聞後，標題改以輸入框上方的**浮動泡泡**掛著（點開可看摘要），不再自動塞進輸入框；可直接送出或先打幾句。

### 遙控

- 遙控 UI 搬到新版手機介面（準心、滾動提示、手勢說明等已對齊實機）。

### 用語解說（Lorebook）

- 桌面與手機皆可編輯用語解說；注入邏輯走共用核心。

### 桌面小修正

- 設定視窗橫向卷軸過粗／礙眼已縮小並避免多餘橫向溢出。

### 下載（包版後再填實際檔名）

- **EXE 版**：`DesktopST 0.4.0.exe`
- **ZIP 版**：`DesktopST-v0.4.0-full.zip`（解壓後執行 `DesktopST.exe`）

## 建議標成「已知限制／尚未包含」

- **官方 APK 正式發行**（B3 階段 7）尚未作為本版主推產物；目前仍以電腦開遠端 ＋ 手機瀏覽器／既有試打路徑為主。
- Spotify、Google 日曆的**授權與進階設定**仍只在電腦版。
- 角色印象（B8）、系統通知（B5）仍延後。

## 內部／開發向（可不放 Release，或縮成一句）

- 業務邏輯持續抽進 `src/core/`；手機／主行程只做薄轉呼叫。
- 導入 vitest（core 純函式層）。
- Capacitor／APK 試打骨架已有，正式包 APK 另排。
- AI 接手文件改為 `CLAUDE.md` 精簡＋依任務選讀。
- 配色：桌面 `theme.css` 與手機 `theme.ts` 色值對齊；key 英文、UI 中文；深色組各有陰影覆寫。細節見 `docs/progress-log.md`「2026-08-07 介面配色擴充」。
