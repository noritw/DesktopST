# DeST v0.5.0 — 更新說明

> 狀態：**草稿**（2026-08-23）。
> 基準：`v0.4.0` → `v0.5.0`（`main`）。
> 對外用途：GitHub Release 內文。技術細節一律不寫，只寫使用者感受得到的變化。

---

## 一句話

**這版讓手機真正獨立了。** 上一版的手機還是「電腦的遙控器」，電腦沒開就什麼都做不了；
這版的手機可以自己聊天、自己提醒你、自己看新聞查天氣，電腦關著也照常運作——
需要的時候，兩邊再把資料同步起來。

---

## 給使用者看的更新（建議直接放進 Release）

### 一、手機可以獨立使用了（本版主軸）

以前手機版必須連著電腦才能用。現在手機自己就是完整的一套：

- **自己聊天**：角色、世界觀、發言身分、用語解說全都存在手機裡，出門在外照樣聊。
- **自己提醒你**：設定的提醒會準時響，**就算把 App 從最近使用清單劃掉也一樣**。
  而且提醒不是照稿念——角色會用自己的口吻當場跟你說。
- **自己看新聞**：個人新聞報可以在手機上瀏覽、釘選、換關鍵字，直接跟角色聊某一則。
- **自己查天氣**：手機用 GPS 定位，比電腦的推測準得多。
  另外新增**地震、颱風、天氣預報的即時查詢**——聊天中提到相關話題時，
  角色會自己去查中央氣象署的最新資料再回你，不會用過期資訊唬你。
- **自己編用語解說**：角色的專有名詞設定可以直接在手機上增修。
- **自己匯出角色**：角色卡（PNG／JSON）與設定包都能在手機上匯出分享，格式與電腦版互通。

> 目前手機上還做不到的：Spotify 與 Google 日曆的授權仍然只能在電腦上完成。

### 二、電腦與手機之間的資料同步

手機獨立之後，兩邊各自都會累積資料，所以這版做了完整的同步機制：

- **一鍵切換**：App 裡可以直接在「用手機自己的資料」與「連電腦」之間切換，不用重開。
- **切換前先看差異**：會列出兩邊有哪些不一樣，**逐項讓你選**要用手機的還是電腦的，
  不會自作主張整包蓋掉。也有「全部用手機／全部用電腦」的快捷。
- **對話用「合併」而不是二選一**：兩邊各自聊過的訊息會互相補齊，不會逼你犧牲一邊。
- **設定也能同步**：模型、對話上限、記憶、配色、模組開關等都能逐欄比對後同步。
  **API 金鑰永遠不參與同步**，任何情況下都不會被傳來傳去。
- **可以刪除**：同步畫面上能直接刪掉不要的整則對話，刪掉之後也不會被同步again補回來。
- **提醒清單也能同步**：手機與電腦的提醒可以互相比對同步；鬧鐘狀態、觸發紀錄這類裝置本地的東西不會被對方覆蓋。

### 三、可以接自己電腦上跑的 AI 模型了

新增「本機／自訂端點」這個供應商，可以接 Ollama、LM Studio 等自己架的模型。

- **主要模型與輔助模型可以分開設定**，各用各的端點。
  例如「主要對話用雲端模型、雜項工作用自己電腦上的免費模型」這種省錢組合是可行的。
- 本機模型**不需要填 API 金鑰**。
- 可用型號會在按下「測試連線」時自動抓回來，不用手動輸入。

### 四、角色表情

- **可以自己換表情了**：對話記錄裡任何一則訊息都能手動指定要顯示哪張表情圖。
- **手機也能新增表情圖片**，並且可以框選臉部範圍決定要顯示圖片的哪個部分。
- 修好了表情在不同裝置之間對不起來的問題。
  ⚠️ **這次修正之前產生的舊訊息不會自動修好**，換一台裝置看仍會顯示主圖，
  需要手動「換表情」補一次；之後新產生的訊息不受影響。

### 五、Android 桌面小工具

可以把角色的最新對話放到手機桌面上，不用打開 App 就看得到。

- 跟著**目前的對話**走，不綁定特定角色。
- 可以把重要的訊息**釘選**在小工具上。
- 四種尺寸自動調整版面；可挑 12 組配色，底色透明度也能自己拉。
- 點一下就跳回 App 對應的那則訊息。

### 六、全新的「飲食記錄」App（獨立 App，與 DeST 分開安裝）

這一版另外附一支獨立的飲食記錄 App：

- **拍照估熱量**：拍下食物讓 AI 估算熱量與營養，可以先補充說明（「這碗比較大」）再估。
  支援多張照片、營養標示表優先辨識。可挑用哪家模型，**也能用自己電腦上的本機模型**。
- **手動記錄**：關鍵字快速入帳、自建食物庫（照片／品牌／口味）、份量調整。
- **手錶與體重計連動**（選配）：透過 Health Connect 讀取體重、體脂，
  以及手錶當天的實際消耗熱量，動態調整今天的熱量上限。
- **桌面小工具**：四種尺寸、進度條、快速記錄與拍照的捷徑。
- **統計頁**：熱量與營養的趨勢回顧。
- 資料完全存在手機本地，可自行匯出備份。

### 七、Google 日曆驅動提醒（桌面版）

桌面版現在會讀取你 Google 日曆事件自帶的提醒設定，自動轉成 DeST 的提醒——Google 那邊改提醒時間，DeST 這邊也會跟著更新，不用兩邊分別設定。開機、每 8 小時、以及打開日曆設定頁時都會自動掃描一次。目前僅桌面版支援，手機版還沒做。

### 八、安全性與資料保存提醒（請務必看一下）

這版新增了兩則提醒文字，也在這裡說明：

- **配對用的 QR code／配對碼，等同於能連進你電腦資料的鑰匙**，請不要外流或分享截圖。
  另外「使用中繼」選項預設是開啟的，開啟後手機同步會透過中繼伺服器讓資料可從網際網路連入
  （有權杖保護）。只想在自家網路內使用的話，請自行關閉這個選項。
- **你的資料沒有任何雲端備份。** 電腦與手機上的資料都只存在本機，
  硬碟損壞、解除安裝、手機遺失或恢復原廠設定都會造成資料**永久遺失**。
  請自行使用角色卡／設定包的匯出功能定期備份。
  這是「免費使用、資料不上雲」換來的代價，作者不對資料遺失負責。

### 九、其他修正與改善

- 提醒的通知改用高重要性頻道，不會再安靜地躺在通知欄裡沒人發現。
- 時間顯示統一跟隨手機的語系習慣（例如「下午 4:43」），不再兩邊長得不一樣。
- 手機返回鍵修好了，不會再操作到一半突然跳回首頁或直接關掉 App。
- 電腦端換了角色主圖後，手機端不會再一直顯示舊圖。
- 訊息支援 Markdown 斜體；輸入框會自動撐高；「說點什麼」生成中可以中途停止。
- 修正手機在弱網或電腦關機時會卡在「載入中⋯⋯」不動的問題。
- 新聞原文連結抓取、關鍵字分組編輯等多項修正。

## 關於 APK
