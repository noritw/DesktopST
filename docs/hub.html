把 AI 角色帶在身邊，
也把三餐記下來

DeST 從桌面上的 AI 角色寵物開始，現在多了手機獨立版， 以及跟角色扮演無關、單純好用的飲食記錄 App「食記」。 三個各自獨立，也可以只挑一個用。

三個東西，怎麼選？

點卡片看各自的完整介紹與下載方式。

Windows

DeST 桌面版

Windows 桌面程式

角色站在你的電腦桌面上，填入 API Key 就能聊天。支援自訂角色、便利貼、提醒、多種色系。

查看桌面版介紹 →
Android

DeST 手機版

Android 獨立 App

不用開電腦，手機上就能單機跟角色聊天；也能跟電腦版同步角色、對話與設定。內建天氣、提醒、個人新聞報。

查看手機版介紹 →
Android

食記

Android 獨立 App

飲食記錄與熱量追蹤 App，拍照就能估熱量，可接手錶讀取體重與消耗熱量。跟 DeST 角色扮演無關，單純好用的記錄工具。
