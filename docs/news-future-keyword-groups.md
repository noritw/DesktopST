# 新聞模組 — 進階構想（關鍵字分組 / 角色卡關鍵字）

> 狀態：**未實作、規格外、待討論定案。** 本檔只記錄方向，避免日後忘記討論內容。
> 提出日：2026-06-03（owner）。相關：`docs/news-module-design.md`。

## 構想

目前新聞興趣關鍵字是**全域單一組**（存模組設定信封）。owner 希望未來支援「分組 + 切換」：

1. **角色卡自帶新聞關鍵字**
   - 例：藝術家角色自帶「藝文展覽」「獨立電影」。
   - 該角色感興趣的關鍵字隨角色走；角色在桌面（或正在發話）時，他的關鍵字併進抽選池。
   - 效果：不同角色聊的新聞自帶各自的取向（藝術家多聊藝文）。

2. **關鍵字分組，可依情境切換**
   - 把興趣關鍵字分成多組（命名）。
   - 切換來源候選：
     - **情境（Scene preset）**：日常情境 → 現實新聞組；奇幻情境 → 空想 / 設定向主題組。
     - **桌面上的角色群組**：依當前在桌面的角色自動切組。

## 可重用的既有結構

- Scene preset（情境分頁）、Persona / World preset：已有「具名預設 + 切換」的心智模型與存取。
- 角色卡欄位（SillyTavern 相容）：可考慮加一個 `newsKeywords` 之類的選填欄位。

## 待決問題（討論時要釐清）

- 多角色同時在桌面、各自有關鍵字時，抽選池如何合併 / 加權？
- 關鍵字組與 Scene preset 是「綁定」還是「各自獨立、手動對應」？
- 角色卡關鍵字是「取代」全域組還是「疊加」？
- 匯入 / 匯出（DST Pack、ST PNG）要不要帶這些關鍵字？
